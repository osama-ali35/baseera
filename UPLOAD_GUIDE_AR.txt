طريقة رفع بصيرة إلى GitHub

1. فك الضغط بواسطة Extract All.
2. افتح المجلد الناتج حتى ترى dist وREADME.md مباشرة.
3. افتح https://github.com/osama-ali35/baseera
4. اختر Add file ثم Upload files.
5. اسحب جميع محتويات المجلد، بما فيها مجلد dist، إلى منطقة الرفع.
   لا ترفع ملف ZIP نفسه ولا المجلد الخارجي الذي يضم الملفات.
6. يجب أن يظهر dist/app.js بهذا المسار، وليس Baseera_GitHub_Baseline_v03/dist/app.js.
7. انتظر اكتمال الرفع، واكتب في رسالة الحفظ:
   Import pre-challenge Baseera v0.3 baseline
8. اضغط Commit changes.
9. أبلغني بانتهاء الرفع للتحقق من الملفات.

النسخة الحالية للتوثيق وليست المنتج النهائي. لا يوجد فيها اتصال OpenAI أو RAG أو خدمة صوتية بعد. لا تضف أي مفتاح API أو كلمة مرور إلى الملفات.

README.md الموجود في المستودع يحتوي على عنوان فقط؛ سيستبدل بملف التوثيق الموجود في هذه الحزمة.
