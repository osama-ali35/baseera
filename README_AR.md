# بصيرة — النسخة السابقة للتحدي 0.3

إعداد د. أسامه سيد عبدالقوى. هذا مستودع النسخة التجريبية السابقة للتحدي، وليس المنتج النهائي.

## التشغيل المحلي

من مجلد المشروع، شغّل:

```sh
python -m http.server 8000 --bind 127.0.0.1 --directory dist
```

على Windows يمكن استخدام `py` بدل `python`. افتح http://localhost:8000 . لا تفتح index.html مباشرة؛ المسارات وخدمة العمل دون اتصال تحتاج خادمًا. للنشر يجب تقديم dist من جذر نطاق الموقع عبر HTTPS، وليس من مسار فرعي.

## الموجود حاليًا

خمسة دروس إنجليزية، أسئلة اختيار من متعدد قبل التعلم وبعده، خرائط مفاهيم، ثلاث صور توضيحية، وإعدادات تطبيق ويب قابل للتثبيت على الأجهزة المتوافقة. الإجابات محفوظة في ذاكرة الصفحة فقط وتُمسح بتحديثها. الكتابة الحرة غير مقيمة آليًا.

## ما لم يُنفذ بعد

لا اتصال بنموذج لغوي، ولا RAG، ولا خدمة صوتية، ولا مراجعة شرعية متخصصة مكتملة. لم تُثبت فعالية تعليمية مقاسة. يلزم اختبار التثبيت والعمل دون اتصال على أجهزة فعلية.

## توثيق البداية

ملفات التطبيق مستوردة دون تعديل من النسخة السابقة للتحدي. راجع BASELINE.md وBASELINE_MANIFEST.json. الرفع إلى GitHub لا يغير تاريخ إنجاز العمل؛ إضافات 4–6 أكتوبر توثق لاحقًا بصورة مستقلة.

لا تضع مفتاح OpenAI في هذا المستودع أو ملفات واجهة المستخدم. سيُحفظ ضمن إعدادات خادم عند تنفيذ الربط.
